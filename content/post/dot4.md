# Daily Operation & Thought

## Engineering Managerのこれから──AI時代における「役割」の静かな再構築

生成AI、特に大規模言語モデル（LLM）が日常に浸透するなかで、自分の役割は徐々に輪郭を失っていくように感じる。

かつて「エンジニアリングマネージャー（EM）」といえば、タスクの進捗を追い、設計の妥当性を確認し、時にはコードをレビューしながら、チーム全体の生産性と士気を保つ存在だった。けれども、今やその多くが、静かにLLMへと引き渡されている。

この変化は終わりを意味するのではなく、静かな問いかけであるようにも思える。

「あなたは、何を手放し、何を引き受けるか？」

---

## 1. 手放すことで見えてくる、新しい輪郭

昔ながらの「EM像」が意味を持たなくなる──それはたしかに喪失のようにも感じるが、一方で空いたスペースにこそ、新しい価値が宿るのではないか。

| 領域         | 新たに浮かび上がるEMの役割            |
| ---------- | ------------------------- |
| AIと人の共創設計  | LLMを前提に、人間の創造性や感性を活かす環境設計 |
| 戦略と組織の橋渡し  | ビジネスとエンジニアリングを双方向につなぐ翻訳者  |
| 曖昧さのマネジメント | 明文化されない問題・価値観を扱うファシリテーター  |
| AI文化の耕し手   | プロンプト設計、倫理、運用を含む土壌づくり     |

いずれも、人でなければ担えない。

---

## 2. どこに立ち、どこへ向かうか──組織内での「重力圏」

EMとして、どの重力圏に自分を位置づけるか。

| 重力圏 | 引力の中心         | そこで求められる動き      |
| --- | ------------- | --------------- |
| 技術  | LLMやAI支援の設計判断 | ツール選定、設計指針の再構築  |
| 組織  | チームの信頼と越境     | 文化形成、育成、多様性の調整役 |
| 戦略  | 事業・経営との整合性    | 技術投資の妥当性判断、言語化  |

どの軸に重心を置くかで、見える景色は大きく変わる。

---

## 3. 自分の履歴に、次の役割の種を探す

ふり返ってみれば、いくつかの経験が手元にある。

* 海外チームとの橋渡し
* 日本語だけだったチームの英語化
* 機能の一部を海外へ移管
* 現場と経営を往復する日々

これらはすべて、AIでは置き換えられない「越境」の実践だった。

| 経験      | これから活かす方向性         |
| ------- | ------------------ |
| グローバル連携 | 多国籍チーム＋LLMの運用設計    |
| 言語化と翻訳  | AI活用の前提となる文脈整備と橋渡し |
| プロセス設計  | AI時代の開発文化とプロセスの標準化 |

---

## 小さく試し、静かに耕す

何から始めるかは大きな問題ではない。大切なのは、変化の実感を、言葉と行動に変えることだ。

* チームでCopilotやGPTの活用を試してみる
* 自分の業務を棚卸しし、「これはAIに委ねてもよいか」と自問する
* 「これからの自分の役割は何か？」を短く言語化してみる

誰に見せるでもなく、その言葉を胸にしまっておくだけでもいい。そういう「静かな宣言」が、行動の芯になる。

---

## おわりに

変化は突然ではなく、少しずつ空気のように満ちてくる。だからこそ、急ぐ必要はない。ただ、その変化に対して耳をすませ、言葉を見つけ、手を動かし続けることが、自分にとってのEMという仕事の本質かもしれない。

AIが多くの業務を肩代わりする時代に、人間がやるべき仕事とは何か──

その問いに対し、完全な答えを出す必要はない。ただ、問い続けられる自分でいたいと、今は思っている。
